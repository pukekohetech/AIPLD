AI IN PRACTICE — OFFLINE EDITION 1.2

OPEN THE TOOLKIT
1. Download the ZIP and extract the whole AI_in_Practice folder.
2. Open index.html in a current browser such as Chrome, Edge or Firefox.
3. Keep the references folder beside index.html so the curriculum links work.

You do not need to install anything or sign in to read and use the toolkit.
The toolkit and included curriculum PDF work without internet access.
Links to other original guidance and AI services need internet access.

PLAN A LESSON
1. Open Curriculum finder. Choose a learning area and Year 9, Year 10 or a language proficiency stage.
2. Search for a topic if needed. Open “Read knowledge, practice & teaching example”.
3. Read the preparation, worked example and evidence to collect. Open a related lesson.
4. Adapt the learning intention (LI) and success criteria (SC) to the precise content your class will learn. Use “Copy LI & SC” or “Make my own copy”.
5. Teach the content and collect the evidence described in the lesson. An AI response alone is not evidence of student learning.

There are 29 student lesson activities with an LI, three observable SC and an evidence check. Seven other resources are teacher guides. The 17 curriculum connections are selected examples, not a complete curriculum map. Read the original page when planning a programme. The curriculum summaries are paraphrased; teaching activities and LI/SC are teacher-designed. Senior adaptations need a separate subject and assessment check.

SAVE AND REUSE YOUR EXAMPLES
Use Add example to record your own activity. Add tags, classroom steps, an optional prompt, LI/SC and evidence. Use Compare for up to three examples. Editing an example keeps up to ten earlier versions of its key fields.

Examples are saved in this browser profile on this device. They do not sync automatically between devices or with any hosted version.

Before replacing an older download, moving or renaming the HTML file, or changing browsers:
1. Open your older copy and use My examples > Export to save a JSON backup.
2. Open the new index.html and use My examples > Import to bring it in.
3. Check your examples are present. Imports add new copies and preserve existing examples.

Use Export regularly. Clearing browser data or changing the file path may make a saved collection unavailable. Keep student names and identifying records out of examples. If browser storage is blocked, the guidance is still readable but saving may be unavailable.

EDITABLE SOURCE (OPTIONAL)
The offline-source folder contains the complete editable offline app.
To rebuild it, install Node.js 20 or later, then run these commands inside offline-source:
  npm install
  npm run build
This creates ../index.html. Keep the references folder beside the rebuilt file.
To run source checks: npm test
Internet access is needed to install the source dependencies initially.
