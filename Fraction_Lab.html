Your learning passport

Add the name to appear on your certificates. Use a first name or school-approved nickname. Nothing is uploaded.

Shared computer? Start a new learner to remove the previous learner's saved progress. Changing the name also starts fresh; changing class or school does not.

How the lab works

1. Predict, then move one thing

Choose a section, make a prediction, and use the sliders or number boxes. Compare the picture and the calculation. The whole and the units matter.

2. Practise with support

Choose Start, Build or Stretch. Worked examples show each step. Practice offers hints, answer checks and a new random question. Enter a number, a fraction such as 3/4, or a mixed number such as 1 1/2. Round decimal answers to two places.

3. Earn a section certificate

Enter a learner name, then take a five-question certificate check. Answer each question once; solutions appear after submission. Four or five correct questions earn that section's certificate at the selected level. You can retry a new check.

4. Print a relief class set

Open Relief class sets. Select the sections, level, class size and four or six questions. Generate numbered versions, then print student sheets, answer keys or teacher notes separately. Keep the seed and settings to reproduce a set.

Privacy and limits

No internet or account is needed. Progress is stored only in this browser on this device; browser settings, clearing data, moving the file or using a shared device may affect it. Print certificates before clearing progress. This is a self-check learning activity, not a secure assessment or a class tracking system. Optional class rosters are not saved between visits.

Printing

Use the page's print buttons, A4 paper and 100% scale. Turn browser headers and footers off. Colour is optional; text labels and outlines remain. Your browser's print dialog can also save a PDF.
